    Dessiner une image

    Ajoutez une image, modifiez le dessin, puis ajoutez la suivante pour créer votre animation. La gomme laisse un fond transparent. Seau : cliquez dans une zone fermée de même couleur. Formes : cliquez-glissez ; largeur et hauteur égales pour un cercle ou un carré.

    JPEG, PNG, WebP, GIF, SVG, AVIF, BMP et autres formats lisibles par votre navigateur · 15 Mo maximum par image. HEIC, TIFF et fichiers de création peuvent nécessiter une conversion en PNG/JPEG. Les images sont centrées sans déformation sur 64 × 32 pixels ; la transparence est conservée. Les fichiers animés sont importés comme une image fixe. Le dernier import peut être retouché dans la grille. La séquence reste disponible tant que cette page reste ouverte.
